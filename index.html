Conecte o seu projeto Supabase

Abra o arquivo config.js e substitua os dois valores de exemplo pela URL e pela chave pública (anon) do seu projeto.

window.ESCOLA_CONFIG = {
  supabaseUrl: "https://SEU-PROJETO.supabase.co",
  supabaseAnonKey: "SUA-CHAVE-ANON"
};

As instruções completas estão no README.md.
